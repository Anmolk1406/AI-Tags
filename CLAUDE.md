# noon Flow Kit: conventions for AI-assisted edits

This is a Vite + React 19 + TypeScript prototype kit for noon app demos, published as the npm package `@noon/flow-kit`. It is not production code and it is not bappzaar. Human contributors follow [CONTRIBUTING.md](./CONTRIBUTING.md); the same rules apply to you.

- **Tokens first.** Colours, spacing, radius and type live in `src/foundations/tokens.ts` (raw palette in `palette.ts`). In CSS use `var(--nk-color-<kebab>)`, `var(--nk-space-s12)`, `var(--nk-radius-r16)`, `var(--nk-type-<kebab>)` (font shorthand). In TSX use `<Text variant color>`. Don't hardcode a hex that already exists as a token.
- **Reuse central components** from `src/components` (import from `'../../components'`): `Button` (incl. NoonButton presets `noon`/`noonSecondary`/`noonGhost`/`noonDotted`, `loading`, `titleCase`), `Spinner`, `Switch`, `Checkbox`, `HtmlText` (server-HTML tags), `Toast` (self-dismissing host), `Divider`/`DashedDivider`/`DottedDivider`, `MaskIcon`, `Skeleton`…; flow-local stores use `createStore` (`src/kit/createStore.ts`). Put flow-only components in `src/flows/<flow>/components/`.
- **One folder per flow**: `index.ts` (defineFlow), `tokens.ts`, `data.ts` (copy and mock content), `*Screen.tsx`, `*.module.css`. Register new flows in `src/flows/index.ts` (or run `npm run new-flow`).
- **Every screen** is wrapped in `<Screen header footer>`, which handles the safe areas and scroll. Use `<Header>` for pushed screens.
- **Navigation**: `useNav()` → `push / sheet / back / replace / reset / switchTab / toast`. Routes are `flow/screen`; page URLs (`/homepage`, `/plp?query=x`, `/cart`, `/checkout` …) live in `src/kit/routes.ts` (or `ScreenDef.path`) and also work in `nav.push('plp')`.
- **Motion**: use `motion/react` with values from `src/motion/presets.ts`, plus recipes in `src/motion/recipes.tsx`. Register screen transitions in `src/motion/custom/index.ts`.
- **Cross-flow state** (cart, wishlist, coupon) goes through `useDemoStore()`; noon One membership through `useMembership()` (`src/kit/membership.ts`). Set `parent` on flows/screens so Back works when a page is opened directly.
- **Prices** use the dirham sign: `currency` from `src/mocks/products.ts` (U+E001, Noontree) — never the text "AED".
- **Porting from bappzaar / Figma**: analyse → map → implement. Read bappzaar **master** read-only via `git -C ~/bappzaar show origin/master:<path>` (never check out or modify it), resolve every `styles.ts` value to a concrete number/colour, write the flow's `MAPPING.md` (or `FIGMA-MAPPING.md`), then implement from it. Copy comes from `marketplaces/noon/locale/translations/noon-en.json`. Record the source path in the screen's `source` field.
- **Token lint**: `npm run lint:tokens` (`-v <path>` lists findings) reports raw hex/rgba/font literals per folder and fails on any in `src/components`; replace them using `scripts/token-map.json` (literal → `--nk-color-*` / `--nk-palette-*` / `--nk-type-*`).
- **Assets**: put files in `src/assets/<flow>/` (shared ones in `src/assets/shared/`), sized ≈3× display; run `npm run assets:optimize` after adding and keep `npm run assets:check` green.
- **Package**: keep `src/index.ts` / sub-path exports backward compatible; add a CHANGELOG line under Unreleased for user-visible changes.
- **Verify**: `npm run verify` (typecheck app + lib · token lint · lib build), `npm run check:routes`, `npm run test:journeys` (core journeys: behaviour + console errors), `npm run visual:ref` (fidelity against the Figma / app references in `visual/refs/`; a kit screenshot is never a reference) and `node scripts/shot.mjs <route> /tmp/x.png` with `npm run dev` running; for visual refactors `npm run visual:snap` + `visual:diff`.
- **Skills**: `.claude/skills/noon-ui/` (main: design system references, flow catalogue, workflow, validation) plus screen skills `home-page`, `search`, `cart`, `checkout`, `pdp`, each with a `spec.md`. Shared branch resources (screen index, patterns, tooling, per-flow briefs) live in `.claude/resources/`. When you add or rename a component, token, transition, recipe, asset folder, flow or screen, update the matching file (and the flow brief), run `npm run resources:build` and `npm run skill:check`.
- **Icons**: system icons are `<OriginIcon name>` (Origin Design System, `src/assets/icons/origin/`, catalogue `.claude/skills/noon-ui/references/icons.md`). Add icons with `npm run icons:import -- <exported folder>`; never hand-edit `src/components/Icon/originIcons.ts`.
