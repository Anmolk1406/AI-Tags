02 · Solution · Install03 / 05

Pick one way in

Git if you build and change flows in the kit itself. npm if you want the noon screens inside your own React app. Both get the Claude skills.

A

The Git way

Build new pages in the kit repo with Claude.

  1. Clone and install
    git clone https://github.com/arnabdebnath07/noon-app-skill.git
cd noon-app-skill && npm install
  2. Run the preview
    npm run dev            # → localhost:5180/homepage
  3. Open Claude Code in the folder the skills load by themselves
    claude
  4. Ask for a page
    /noon-ui build a loyalty hub with points and rewards
B

The npm way

Use the kit in another React 19 app, skills from the plugin.

  1. Add the skills to Claude Code
    claude plugin marketplace add arnabdebnath07/noon-app-skill
claude plugin install noon-ui@noon-flow-kit
  2. Install the package noon-kit on npm · React 19
    npm i noon-kit react react-dom
  3. Render the flows
    import { NoonPrototype, homeFlow, pdpFlow, cartFlow }
  from 'noon-kit';
import 'noon-kit/style.css';

<NoonPrototype flows={[homeFlow, pdpFlow, cartFlow]}
  initialRoute="home/home" />
Both · optionalConnect Mobbin for research:claude mcp add --transport http mobbin https://api.mobbin.com/mcpthen /mcp → mobbin → Authenticate
